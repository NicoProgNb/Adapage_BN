# Adapage - Bernabé Nicolas

## Pré-prog

Vous trouverez le wireframe dans un sous dossier, éxecuté sur Paint. 

La raison est que j'ai pu faire divers calques, étirer des cadres pour modifier l'affichage, etc... 

La présentation est donc peu qualitative mais fonctionnelle car j'ai précisé ma sémantique. 

Pour chacune des pages, j'ai présenté une vision 375px (mobile) et 1024px (pc). 

J'ai par la suite modifié la présentation, car je suis mon propre client. Le wireframe est donc légèrement différent du produit final. 

## Prog

Présenté en deux fichiers .html, mis en page avec un seul fichier .css. 

Les images étaient au départ appelées via lien URL mais j'ai opté pour un dossier nommé "image".

J'ai retiré les fonds des icônes avant des les appeler dans mon html. 

Pour pointiller, j'aurai pû toutes les dimensionner mais j'ai corriger l'affichage sur le css. 

## Post-prog

Les tests d'affichage sont validés (375px, 768px, 1024px, 1440px, Zoom 200%). 

Le test Validator est validé sur les deux html.
